Forecasting and regime analysis of accounting indicators of four Brazilian
power-transmission companies: data and code

Contents
  Input data (repository root)
    dados_input_trimestral.csv   26 candidate regressors, quarterly, 2010-Q1 to 2025-Q4
    resultado_bruto.csv          Net Revenue series (CVM DRE item 3.01), four companies
    lucro_consolidado.csv        Net Income series (CVM DRE item 3.11)
    despesas_operacionais.csv    Operational Expenses series (CVM DRE item 3.04)
    descricao_empresas.csv       company identification
    *.mat                        the same series in MATLAB format
  config.py                      every parameter of the forecasting pipeline
  paths.py                       every path used by the code
  main.py, src/                  forecasting pipeline (model wrappers, preprocessing,
                                 exogenous selection, evaluation)
  rounds/specs/                  one YAML specification per search round
  outputs/results/               result file of every round
  plot_best_results.py           recomputes the twelve preferred models
  modelos_estaveis/              reproduction entry point, one combination at a time
  scripts/                       scripts that generate the tables of the paper
  results/data/                  series used by the regime-detection half
  results/*.csv                  tables generated by scripts/
  results/hmm_*/                 outputs of the regime-detection half
  hmm_models/Data_mining/        notebooks that build the series from the CVM filings
  hmm_models/Model/              regime-detection code (hmm_n64*.py) and notebooks

Environment
  Python 3.11 or later.  pip install -r requirements.txt
  The pinned versions are those used to produce every reported number.
  The notebooks in hmm_models/Data_mining/ read database and path settings from a
  .env file; copy .env.example to .env and fill in the values.

Reproduce
  Forecasting half
    python plot_best_results.py
        recomputes the twelve preferred models under config.py and exits with a
        non-zero status if any FIT% drifts by more than 0.5 percentage point
    python modelos_estaveis/reproduzir_combo.py --todos
    python scripts/champion_specs.py --check
    python scripts/simple_benchmarks.py --check
    python scripts/persistence_vs_fit.py --check
    python scripts/ar1_walkforward.py --check
    python scripts/dm_multiplicity_panel.py --check
    python scripts/revenue_netincome_correlation.py --check
        each --check recomputes a table and compares it with the CSV in
        results/

  Regime-detection half (run from the repository root)
    python hmm_models/Model/hmm_n64.py --stage all
    python hmm_models/Model/hmm_n64_sync_inference.py
    python hmm_models/Model/hmm_n64_sync_maxnull.py
    python hmm_models/Model/hmm_n64_sync_tercile_baseline.py --out-dir results/hmm_n64_k3_rerun
    python scripts/make_journal_figures.py

  A new search round is a YAML file in rounds/specs/:
    python main.py --round spec rounds/specs/round_NN.yaml
